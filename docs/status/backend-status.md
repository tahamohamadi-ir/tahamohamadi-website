# وضعیت توسعه بک‌اند (Backend Status)

این سند در تاریخ جولای ۲۰۲۶ برای ثبت دقیق وضعیت پیاده‌سازی، تکنولوژی‌ها و فیچرهای بک‌اند (پروژه TahaMohamadi.ir) تنظیم شده است.

## 🛠 تکنولوژی‌های استفاده شده (Tech Stack)

- **فریم‌ورک اصلی:** Python / Django 
- **ساخت APIها:** Django REST Framework (DRF)
- **معماری:** Headless CMS (ارسال داده‌ها به صورت JSON به فرانت‌اند)
- **ابزارهای کیفیت کد:** Ruff (برای Linting و Formatting)، Pytest (برای Testing)
- **مدیریت Dependency‌ها:** venv / pip (و فایل requirements)
- **دیتابیس:** PostgreSQL (به صورت پیش‌فرض یا SQLite در محیط توسعه)

## ✅ فیچرهای پیاده‌سازی شده (Implemented)

### ۱. معماری Headless CMS
- **مدل‌های انعطاف‌پذیر:** ساختار لازم برای ذخیره داده‌های صفحات و بلاک‌ها به صورت JSON.
- **RESTful APIs:** توسعه اندپوینت‌های API برای ارائه محتوا به فرانت‌اند به صورت کاملاً ساختاریافته.

### ۲. زیرساخت کیفیت نرم‌افزار
- پیکربندی **Ruff** (در `ruff.toml`) برای بررسی کیفیت کدها و اعمال استانداردهای PEP8.
- راه‌اندازی **Pytest** (در `pytest.ini`) برای نوشتن تست‌های خودکار.
- پیاده‌سازی `Makefile` برای اجرای راحت دستورات محیط توسعه، اجرای سرور، تست‌ها و لینترها.

## ⏳ فیچرهای پیاده‌سازی نشده یا در صف توسعه (Not Implemented / TODO)

### ۱. بهبودهای پرفورمنس (Performance & Caching)
- **نصب و راه‌اندازی Celery & Redis:** این ساختار هنوز در بک‌اند تنظیم نشده است. هدف از آن پردازش تسک‌های سنگین در بک‌گراند (مثل ارسال ایمیل‌ها یا پردازش تصاویر) است.
- **کشینگ (Caching) سمت بک‌اند:** استفاده از `django-redis` برای کش کردن کوئری‌ها و ریسپانس‌های API صفحات پابلیک (جهت رسیدن به سرعت زیر 50ms).

### ۲. یکپارچه‌سازی هوش مصنوعی (AI Integration)
- در حال حاضر اندپوینت هوش مصنوعی برای دستیار ادمین پنل به صورت Stub/Mock در فرانت‌اند (مسیر `/api/ai`) پیاده شده است. 
- **TODO:** پیاده‌سازی منطق واقعی اتصال به API‌های LLM (مثل OpenAI یا Anthropic) در بک‌اند جنگو و اعتبارسنجی درخواست‌های ادمین از طریق یک اندپوینت امن در جنگو.

## 📊 معماری پوشه‌ها
- `backend/apps`: ماژول‌ها و اپلیکیشن‌های جنگو (به عنوان مثال برای مدیریت بلاگ، پروژه‌ها و APIها).
- `backend/config`: تنظیمات اصلی پروژه (`settings.py`، `urls.py` و...).
- `backend/media`: مسیر ذخیره‌سازی فایل‌های آپلود شده.
- `backend/tests`: ساختار تست‌های پروژه با `pytest`.
